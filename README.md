# Miniguia-Bleach-NotebookLM
Guia do anime Bleach feito com auxilio da IA NotebookLM, com objetivo de relacionar a Obra Bleach do mangaká japonês Tite Kubo com a psicologia moderna. Esse pequeno estudo tenta trazer o universo de Bleach aliado a uma abordagem psicologica, fazendo a relação entre os personagens e as demais áreas da psicologia.
